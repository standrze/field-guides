How many are nonstandard?

Nine are Midnight-specific. Another six use Mistral voice semantics: 15 operations outside the working OpenAI-compatible subset. Routes shared by dialects are counted once. A familiar URL does not guarantee identical behavior.

One listener. One loaded model.

All calls use the same host and port. An OpenAI SDK uses the base URL http://127.0.0.1:8080/v1; native clients append the full paths below to http://127.0.0.1:8080. Replace the example port with your listener port.

API groupPurposeContract
/v1/models
/v1/chat/completions
/v1/responses		Discovery and inferenceOpenAI-compatible subset
/v1/runtime/*Load, unload, status and managed filesMidnight-specific
/v1/inspector/*Geometry and bounded activation tracesMidnight-specific
/v1/audio/*Speech and voice resourcesOpenAI and Mistral dialects; see each call
/v1/vision/statusOptional vision worker statusMidnight-specific

The runtime owns one loaded selection per server process. Inspection and generation lease that same selection. Switching drains active work, releases the old backend and cleans up unused memory before loading its replacement. Discovery returns one ready model or an empty list; it does not load or advertise every model on disk. Stored response history belongs to the listener and can survive model unload.

Existing URLs and response contracts are preserved. Runtime, inspector, audio, vision and Responses handlers are separated internally, sharing the listener rather than creating additional servers.

01 · OpenAI-compatible

The familiar calls.

Use an OpenAI-style client with base_url="http://127.0.0.1:8080/v1". Set the actual listener port. Read the model id from discovery; the common name is presentation metadata.

CallContract / statusUse it for
GET/v1/modelsOpenAI-compatibleAvailableList the loaded model; empty while none is ready. Not a disk inventory.
GET/v1/models/{id}OpenAI-compatibleAvailableRetrieve the loaded model by its exact, URL-encoded API ID.
POST/v1/chat/completionsOpenAI-compatibleModel-dependentText chat and SSE. Image chat requires the vision backend; that path is non-streaming.
POST/v1/responsesOpenAI-compatibleText modelsText responses, function tools, optional SSE and stored continuation. Local subset.
GET/v1/responses/{id}OpenAI-compatibleStored onlyRetrieve a response retained by this listener, even after model unload.
DELETE/v1/responses/{id}OpenAI-compatibleStored onlyDelete one saved response. Does not delete model weights.
GET/v1/responses/{id}/input_itemsOpenAI-compatibleStored onlyList inputs. Query: order=asc|desc, limit=1..100, after=<item-id>.
POST/v1/audio/speechOpenAI-compatibleSpeech modelOpenAI body uses voice; returns audio. Also accepts the Mistral voice_id dialect. Do not mix dialects.
Compatibility is a subset

Chat and Responses support model-dependent tools and structured output. This listener does not offer the full hosted OpenAI service: no embeddings endpoint, Realtime/WebSockets, Files API, transcription, hosted tools, or background response cancellation.

02 · Midnight-specific / nonstandard OpenAI

Control and inspect.

These are existing Midnight extensions. You can use standard chat without calling them. Load/unload is asynchronous; a 202 response means accepted, not ready.

CallContract / statusUse it for
GET/v1/runtimeMidnight-specificAvailableRead phase, modelGeneration, loadedModel, memory and lastError.
POST/v1/runtime/loadMidnight-specificLocal controlLoad a folder/path; optional name sets the routing ID. Returns 202; poll runtime until ready.
POST/v1/runtime/unloadMidnight-specificLocal controlUnload weights from RAM; keep disk files. Send {} or selection guards. Returns 202.
GET/v1/runtime/downloadsMidnight-specificLocal controlList managed downloads with repository, revision and inUse. Not every manually copied model.
POST/v1/runtime/removeMidnight-specificDestructiveDelete a managed download by folder name. Refuses unmanaged or in-use files.
GET/v1/inspector/runtimeMidnight-specificAliasManaged listener: same runtime state as /v1/runtime. Legacy direct handler: process identity only.
GET/v1/inspector/modelMidnight-specificText inspectorModel/layer geometry, quantization, modelCard and traceCapabilities. Check traceSupported.
POST/v1/inspector/traceMidnight-specificSupported modelsExplicit, bounded activation capture. Requires layers and tokenPositions; not a training call.
GET/v1/vision/statusMidnight-specificVision backendRead status from the selected optional vision worker.
Local control contract

Load, unload, downloads and remove require a loopback client, Content-Type: application/json (including GET downloads), and no Origin header or cross-site browser request. Use a native client or terminal. remove deletes files; unload only releases RAM.

03 · Mistral-style / nonstandard OpenAI

Voices are a separate dialect.

These contracts follow Mistral voice resources. Preset discovery depends on the loaded voice catalog. The current handlers do not create, edit, delete or return source samples for bundled voices.

CallContract / statusUse it for
GET/v1/audio/voicesMistral-stylePreset discoveryList voice metadata. Query: limit, offset, type=all|custom|preset.
POST/v1/audio/voicesMistral-styleUnsupportedMistral JSON voice creation is rejected. OpenAI multipart creation shares this path and returns an unsupported-feature error.
GET/v1/audio/voices/{id}Mistral-stylePreset discoveryRetrieve metadata for a known preset voice ID.
PATCH/v1/audio/voices/{id}Mistral-styleRead-only presetsRoute recognized, but bundled presets cannot be changed.
DELETE/v1/audio/voices/{id}Mistral-styleRead-only presetsRoute recognized, but bundled presets cannot be deleted.
GET/v1/audio/voices/{id}/sampleMistral-styleUnavailableRoute recognized; bundled checkpoint does not provide original sample WAV files.

POST /v1/audio/speech is counted above, once. With voice, it uses OpenAI semantics; with voice_id and related fields, it uses Mistral semantics. Mistral non-streaming output is JSON with base64 audio_data; OpenAI output is audio by default. Speech SSE ends at EOF, not a chat [DONE] marker.

04 · Copy a call

Start with discovery.

These examples are for a terminal, not browser-side control. Replace the port and IDs. Examples use curl and jq; buttons only copy text and never execute a request.

1 / Find the routing ID

BASE=http://127.0.0.1:8080
curl -sS "$BASE/v1/models"
MODEL=$(curl -fsS "$BASE/v1/models" | jq -er '.data[0].id')

A failed jq lookup means no model ID was returned. Check runtime readiness before generating.

2 / OpenAI-compatible streamed chat

jq -n --arg model "$MODEL" '{model:$model,
  messages:[{role:"user",content:"Explain wireless broadcasting."}],
  max_tokens:128,stream:true,stream_options:{include_usage:true}}' |
curl -N "$BASE/v1/chat/completions" \
  -H 'Content-Type: application/json' --data-binary @-

3 / OpenAI-compatible Responses

jq -n --arg model "$MODEL" '{model:$model,
  input:"Write a brief invitation to Sunday tea.",
  max_output_tokens:128,store:false}' |
curl -sS "$BASE/v1/responses" \
  -H 'Content-Type: application/json' --data-binary @-

Use store:true when you need GET /v1/responses/{id} or previous_response_id continuation.

4 / Midnight model lookup and common name

curl -sS "$BASE/v1/inspector/model" |
  jq '{id,modelCard,modelType,layerCount,traceSupported}'
curl -sS "$BASE/v1/models" |
  jq '.data[] | {id,name:.model_card.name}'

Edit model-card.json in the selected folder; reload to refresh metadata. Route requests by id, not name.

5 / Midnight load and readiness

curl -sS "$BASE/v1/runtime/load" \
  -H 'Content-Type: application/json' \
  -d '{"model":"talkie-1930-13b-it-midnight-q4r8-scalesearch-attn8",
       "contextLength":2048,"maxTokens":256}'
curl -sS "$BASE/v1/runtime" | jq '{phase,lastError,loadedModel}'

Load changes the active model. Repeat the status GET until phase is ready or lastError explains failure; then discover the model ID again.

6 / Midnight unload; keep the files

curl -sS "$BASE/v1/runtime/unload" \
  -H 'Content-Type: application/json' -d '{}'
curl -sS "$BASE/v1/runtime/downloads" \
  -H 'Content-Type: application/json'

For deliberate deletion only: POST /v1/runtime/remove with {"model":"managed-folder-name"}. In-use or unmanaged folders are refused.

7 / Mistral-style preset discovery

curl -sS "$BASE/v1/audio/voices?limit=10&offset=0&type=preset"

Load a supported voice model first. Text models do not gain speech capability merely because the route exists.

05 · Client notes

Details that matter.

Lowlight, lowlight-relay and highlight

These clients discover models with GET /v1/models. They read optional model_card.name and model_card.description. Model pickers show the common name with the routing ID available; missing or malformed cards fall back to the ID. Selection and generation always use id, never the common name. Lowlight refreshes on reconnect; highlight has a Refresh action. After editing a folder's card, reload that model in Midnight, then refresh the client. This is metadata for the currently advertised model, not a listing of all cards on disk.

ID ≠ display name

id routes calls. model_card.name is editable metadata. Inspector uses modelCard. Extra metadata fields are Midnight extensions on standard routes.

Match field styles

OpenAI inference uses snake_case: max_tokens or max_output_tokens. Midnight load uses camelCase: contextLength, maxTokens.

One active selection

Discovery lists the loaded selection, not the whole model folder. Capabilities follow that selection. Guard restoration with expectedGeneration and expectedInstanceID.

  • Stored responses: defaults to enabled; in-memory only, up to 128 responses / 64 MiB / one hour. Restart clears history. store:false disables storage for that result.
  • Streaming: Chat uses SSE chunks and [DONE]. Responses uses typed events. Disconnect cancels the active request; there is no response-cancel-by-ID endpoint.
  • Inspection: discover capabilities before tracing. A minimal prefill request includes question, maxTokens:0, layers:[0], and tokenPositions:{prefill:[-1],decode:[]}. Send the discovered model ID and runtimeGeneration to reject a stale selection.
  • Limits: use advertised context and output ceilings. A larger request does not extend a checkpoint's trained context. Tool calls return instructions to the client; Midnight does not execute your tools.
  • Errors: 400 invalid request/limits; 403 local-control restriction; 404 missing model/response; 409 busy or stale selection; 422/501 unsupported feature. Inspect the returned error code.
  • Connection: examples assume local loopback. This listener does not validate an OpenAI API key; an SDK placeholder key is not authentication.
