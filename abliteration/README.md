# Abliteration Methods Guide

This folder is a completely static website. It uses only HTML, CSS, and a small amount of
browser-side JavaScript.

The published folder does not require AI, a backend, Swift, Node.js, a database, API keys, or a
build step. Progress is stored locally in the visitor's browser with `localStorage`. The five
recommended research papers are served as local PDFs with the guide.

This directory is generated publishing output. The Markdown authoring sources and Swift generator
are intentionally not required to host or browse it.

## GitHub Pages

- Field-guide library: <https://standrze.github.io/field-guides/>
- Live guide: <https://standrze.github.io/field-guides/abliteration/>
- Pages publishes the library from the root of its `main` branch and this guide from the
  `abliteration/` folder.

All site assets use relative URLs, so repository and project-page base paths both work.
